# 共有 learnings の記録方針

- チームで再発を防ぐ必要がある知見だけを記録する。個人の好みや環境固有の設定は各ツールの個人メモへ置く
- 対象は生成失敗、検証エラー、仕様差異、審査却下理由、対話の詰まり、安全フックの誤検知
- `.agents/learnings/index.md` に日付・1行要約・詳細へのリンクを追加し、詳細は `workflow.md`、`pipeline.md`、`publish.md` の該当トピックへ書く
- 各エントリは「事象 → 原因 → 対処 → 再発防止」の順にする
- 実行サイクルの最後に確認し、記録対象がなければタスクレビューへ「学びなし」と書く
