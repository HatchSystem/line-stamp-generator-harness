# pipeline の学び

## 2026-09-03 submit pack validation

- 事象: ファイル名と最大寸法だけの検査では、小さすぎる画像、奇数寸法、DPI欠落、非対応モード、完全透明画像、ZIPとローカル提出物の不一致を見逃せる
- 原因: 画像単体の外形検査と、ZIPを最終成果物として照合する検査が分離されていなかった
- 対処: PNGの最小・最大寸法、偶数寸法、元モード、72dpi以上、透明背景、可視内容、容量を検査し、ZIPのmember一覧と各バイトを検証済みローカルファイルへ照合するようにした
- 再発防止: 正常系だけでなく境界値、破損ZIP、完全透明、member差し替えを self-test に含める。パッケージ作成は出力先と同一filesystemの一時領域で行い、管理対象だけを置換しZIPを最後に入れる。古い余剰成果物は黙って削除せず検査エラーとして報告する
