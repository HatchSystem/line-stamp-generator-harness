# 公開申請（P8）と追跡（P9）

エージェントは登録画面の入力・アップロード・確認までを行う。審査時の同意事項を読み「同意します」を選ぶ操作、「審査をリクエスト」、「リリース」はユーザー本人が行い、エージェントは代行しない。

## P8 前提

`python scripts/line_stamp.py check-publish-ready ...` がエラー0で通っていること。次のいずれかに該当する場合は P8 に入らない。

- `publish` が `yes` でない
- `rights` が条件を満たさない。写真では `consent: yes` / `adult: yes`、既存キャラクターでは両方 `n/a` でない
- `validation` が `ok` でない
- `submission` が `drafted` でない（P7 のメタ案が未承認）
- `sales_start` が `manual` でない

## ブラウザ操作

実行環境で利用できるブラウザ操作手段（拡張機能、MCP、CLI のいずれでも可。特定技術に依存しない）を使う。ログインはユーザー本人が行い、エージェントはID・パスワード・認証コードを入力しない。ログイン済みの画面を渡してもらってから開始する。

1. LINE Creators Market のマイページ → 「新規登録」 → 「スタンプ」を開く
2. スタンプの種類: 静止画。個数: SESSION の `count` と一致させる（審査後は変更不可）
3. 英語タイトル・英語説明を入力し、「言語を追加」で Japanese を追加して日本語タイトル・説明を入力
4. クリエイター名、コピーライト、3択の販売エリアと対象国、LINE STORE/ショップのプライベート設定を `meta/submission.json` どおりに設定
5. AI 使用と「写真の使用」は `ai_used` / `photo_used` の明示確認どおりに設定する。写真由来か文字方式だけから推測しない
6. `license_proof.status: user-confirmed` なら、ユーザーが提示した作品の HTTPS URL または対象プロジェクト内のライセンス証明書を指定どおり登録する。証明書の作成、内容の捏造、ログイン情報の入力はしない
7. LINEスタンプ プレミアムは画面の既定値を受け流さず、`premium_participation` どおりに明示設定する
8. 販売開始設定は「手動で販売を開始」を選ぶ。「自動で販売を開始」は選ばない
9. スタンプ画像タブで `submit/<zip>` をZIPアップロードし、main / tab / 01〜NN がすべて表示されるまで待つ
10. タグを設定（任意。時間がなければスキップして良い旨をユーザーに伝える）
11. 販売価格を `meta/submission.json` の値で設定
12. 保存し、画面のプレビューで次を目視確認する
   - 個数、画像の欠け、順番
   - タイトル・説明に誤字や全角混入がないこと
   - AI使用の申告が選択されていること
   - 販売開始設定が「手動で販売を開始」であること
   - main / tab が販売するスタンプのキャラクター・画風と著しく異ならないこと
   - 写真使用、ライセンス証明、プレミアム参加、販売エリアと対象国が承認メタどおりであること
13. 入力内容を箇条書きでサマリし、ユーザーに提示する
14. 「同意事項をご自身で読み、同意できる場合だけ『同意します』を選び、『審査をリクエスト』を押してください。完了したら教えてください」と伝えて停止する。エージェントは同意チェックもリクエストも操作しない

ユーザーが押したと報告したら、SESSION の `submission` を `requested` に更新し、日時を `notes` に残す。

画面の文言やレイアウトが変わっている場合は、推測でクリックせず、見えている項目名をユーザーに伝えて指示を仰ぐ。

## P9 審査の追跡

- ユーザーから依頼があったとき、または定期確認の指示があるときにマイページの状態を確認する
- `審査中`: そのまま報告する
- `承認`: `submission: approved` に更新し、「マイページの『リリース』を押すと販売開始です。押す前に価格と公開設定を再確認してください」と案内する。ユーザーがリリースしたら `released` にする
- `リジェクト`: 理由をそのまま転記し、`submission: rejected` にする。次の対応表で戻り先を決め、修正版は版番号を上げて再検証する

| リジェクト理由の例 | 戻り先 |
|---|---|
| 画像フォーマット・サイズ・透過 | P6（再梱包・再検証） |
| 文字の誤り、視認性 | P4〜P5（該当番号だけ再作成） |
| タイトル・説明・コピーライト | P7 |
| 権利確認書類の要求 | ユーザーに書類提出を依頼。エージェントは書類を作らない |
| 肖像権・権利不明 | P0（素材利用権と本人許諾を再確認。満たせなければ制作停止） |

再申請でも「審査をリクエスト」はユーザーが押す。
