# 登録入力と制作完了（P8）

エージェントは確認済みアカウントで登録画面の入力・アップロード・プレビュー確認までを行い、そこで制作を完了する。審査時の同意、「審査をリクエスト」、審査追跡、「リリース」は制作プロセスの対象外である。

## P8 前提

`python scripts/line_stamp.py check-publish-ready ...` がエラー0で通っていること。次のいずれかに該当する場合は P8 に入らない。

- `publish` が `yes` でない
- `validation` が `ok` でない
- `submission` が `drafted` でない（P7 のメタ案が未承認）
- `sales_start` が `manual` でない

## ブラウザ操作

実行環境で利用できるブラウザ操作手段（拡張機能、MCP、CLI のいずれでも可。特定技術に依存しない）を使う。ログインはユーザー本人が行い、エージェントはID・パスワード・認証コードを入力しない。ログイン済みの画面を渡してもらってから開始する。

1. 現在の画面に表示されたアカウント名、販売者ID、登録先を読み取り、値をユーザーへ提示して「このアカウントと登録先で進む / 別アカウントへ切り替える / P8を中止する」から選んでもらう。承認後、`project ... confirm-account` で `SESSION.md` へ記録する
2. 入力直前に表示値が `SESSION.md` と一致することを再確認する。不一致なら入力せず、再確認を求める
3. LINE Creators Market のマイページ → 「新規登録」 → 「スタンプ」を開く
4. スタンプの種類: 静止画。個数: SESSION の `count` と一致させる（審査後は変更不可）
5. 英語タイトル・英語説明を入力し、「言語を追加」で Japanese を追加して日本語タイトル・説明を入力
6. クリエイター名、コピーライト、3択の販売エリアと対象国、LINE STORE/ショップのプライベート設定を `meta/submission.json` どおりに設定
7. AI 使用と「写真の使用」は `ai_used` / `photo_used` の明示確認どおりに設定する。写真由来か文字方式だけから推測しない
8. LINE から追加資料を求められ、任意の `license_proof.status: user-confirmed` が保存されている場合だけ、ユーザーが提示した HTTPS URL または対象プロジェクト内の資料を指定どおり登録する。資料の作成、内容の捏造、ログイン情報の入力はしない
9. LINEスタンプ プレミアムは画面の既定値を受け流さず、`premium_participation` どおりに明示設定する
10. 販売開始設定は「手動で販売を開始」を選ぶ。「自動で販売を開始」は選ばない
11. スタンプ画像タブで、ルート直下に `main.png`、`tab.png`、`01.png`〜`NN.png` だけを持つ `submit/<zip>` をZIPアップロードし、main / tab / 01〜NN がすべて表示されるまで待つ。内部名 `stampNN.png` のZIPは使用しない
12. タグを設定（任意。時間がなければスキップして良い旨をユーザーに伝える）
13. 販売価格を `meta/submission.json` の値で設定
14. 保存し、画面のプレビューで次を目視確認する
   - 個数、画像の欠け、順番
   - タイトル・説明に誤字や全角混入がないこと
   - AI使用の申告が選択されていること
   - 販売開始設定が「手動で販売を開始」であること
   - main / tab が販売するスタンプのキャラクター・画風と著しく異ならないこと
   - 写真使用、プレミアム参加、販売エリアと対象国が承認メタどおりであること。任意の追加資料を登録した場合は、その参照も一致すること
15. 入力内容を箇条書きでサマリし、ユーザーに「入力内容とプレビューに問題がありますか。問題なし / 修正（項目名）」と確認する
16. 問題なしなら `project --root . complete-production` を実行して `submission: production-complete` にし、次の文だけを結びとして表示する

```text
制作が完了しました。問題なければ審査リクエストを実施してください。
```

審査リクエストの完了報告を求めず、リクエスト後の状態を `SESSION.md` に保存しない。

画面の文言やレイアウトが変わっている場合は、推測でクリックせず、見えている項目名をユーザーに伝えて指示を仰ぐ。
