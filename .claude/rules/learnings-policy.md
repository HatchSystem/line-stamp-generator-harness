# 学びの記録ルール

- 記録対象: 生成の失敗パターン、検証エラーの原因、LINE 仕様の差異、審査却下理由、対話で詰まった点、hooks の誤検知
- `.claude/learnings.md` に「日付 / 1行要約 / トピックファイル」の索引を追記し、詳細は `.claude/learnings/<topic>.md` に書く
- トピック: `workflow`（ゲート・対話）、`pipeline`（画像処理・スクリプト）、`publish`（Creators Market・審査）
- 各エントリは「事象 → 原因 → 対処 → 再発防止（ルール化したか）」の4項目
- 個人の好みや環境固有の気づきは Auto memory に任せ、チームで再発を防ぎたいことだけをここに書く
- 実行サイクル Step 7 で必ず確認し、該当がなければ「学びなし」と todo.md のレビューに記す
