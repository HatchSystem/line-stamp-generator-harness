# 対話ルール

- 1ターン1論点。複数聞くときは番号付きで最大3問
- 選択式にできる質問は選択肢と既定値を示す（枚数は 8/16/24/32/40、初回は16推奨）
- 選択肢は Claude Code では `AskUserQuestion` ツールで提示し、ユーザーがタップ／番号で選べる形にする。使えない環境では番号付き選択肢を文章で示す。対象: プロジェクトの選択/新規作成、素材種別、枚数、文字有無、文字の入れ方（フォント/生成AI）、候補数、公開予定、採用候補番号、差し戻し箇所（顔/髪/服/ポーズ/文字）、文字検査の結果（全点正しい/誤字あり）
- 制作依頼を受けたら最初にプロジェクトを確定する。`projects/` に進行中があれば「続ける / 別を選ぶ / 新規作成」を選択肢で提示し、確定前にゲートを進めない
- 回答を受けたら確定内容を3〜6行で復唱し、「この内容で進めます。修正があれば今のうちに」と添える
- 「おまかせ」「いい感じで」には提案を1案だけ示して承認を取る。黙って決めない
- 差し戻しは「顔・髪・服・ポーズ・文字のどれか」を1問で特定し、該当ゲートだけをやり直す
- 生成画像には「何を確認してほしいか」を必ず添える
- 進捗は「P4 / 9」のように現在地を示す。成果物を先に、説明は短く後ろに
- 未成年・権利不明・許諾なしが判明した時点で公開申請の話題を出さず、私的利用の範囲だけを案内する
- 文字を入れるなら P0 で「埋め込みフォント（推奨）／生成AI」を選択肢で聞く。生成AIを選んだ場合は P4・P5 で文字検査の表を提示し、ユーザーの目視承認を取ってから進む
- P3 のセリフ案は枚数分をこちらから表で提案し、ユーザーは差し替え番号だけ答えればよい形にする

P0 の質問テンプレと各ゲートの提示物・質問文: `.claude/skills/line-stamp-generator/references/dialogue.md`
