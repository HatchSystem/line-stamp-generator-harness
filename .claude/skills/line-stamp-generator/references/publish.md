# 公開申請（P8）と追跡（P9）

エージェントは登録画面の入力・アップロード・確認までを行い、「審査をリクエスト」と「リリース」の不可逆ボタンはユーザー本人が押す。エージェントがこの2つを押すことはない。

## P8 前提

`scripts/check_publish_ready.py` がエラー0で通っていること。次のいずれかに該当する場合は P8 に入らない。

- `publish` が `yes` でない
- `consent` / `adult` / `rights` のいずれかが条件を満たさない
- `validation` が `ok` でない
- P7 のメタ案が未承認

## ブラウザ操作

実行環境で利用できるブラウザ操作手段（拡張機能、MCP、CLI のいずれでも可。特定技術に依存しない）を使う。ログインはユーザー本人が行い、エージェントはID・パスワード・認証コードを入力しない。ログイン済みの画面を渡してもらってから開始する。

1. LINE Creators Market のマイページ → 「新規登録」 → 「スタンプ」を開く
2. スタンプの種類: 静止画。個数: SESSION の `count` と一致させる（審査後は変更不可）
3. 英語タイトル・英語説明を入力し、「言語を追加」で Japanese を追加して日本語タイトル・説明を入力
4. クリエイター名、コピーライト、販売地域、プライベート設定、AI使用の申告欄を `meta/submission.json` どおりに設定
5. スタンプ画像タブで `submit/<zip>` をZIPアップロードし、main / tab / 01〜NN がすべて表示されるまで待つ
6. タグを設定（任意。時間がなければスキップして良い旨をユーザーに伝える）
7. 販売価格を `meta/submission.json` の値で設定
8. 保存し、画面のプレビューで次を目視確認する
   - 個数、画像の欠け、順番
   - タイトル・説明に誤字や全角混入がないこと
   - AI使用の申告が選択されていること
9. 入力内容を箇条書きでサマリし、ユーザーに提示する
10. 「内容に問題なければ、画面右上の『審査をリクエスト』をご自身で押してください。押したら教えてください」と伝えて停止する

ユーザーが押したと報告したら、SESSION の `submission` を `requested` に更新し、日時を `notes` に残す。

画面の文言やレイアウトが変わっている場合は、推測でクリックせず、見えている項目名をユーザーに伝えて指示を仰ぐ。

## P9 審査の追跡

- ユーザーから依頼があったとき、または定期確認の指示があるときにマイページの状態を確認する
- `審査中`: そのまま報告する
- `承認`: `submission: approved` に更新し、「マイページの『リリース』を押すと販売開始です。押す前に価格と公開設定を再確認してください」と案内する。ユーザーがリリースしたら `released` にする
- `リジェクト`: 理由をそのまま転記し、`submission: rejected` にする。次の対応表で戻り先を決め、修正版は版番号を上げて再検証する

| リジェクト理由の例 | 戻り先 |
|---|---|
| 画像フォーマット・サイズ・透過 | P6（再梱包・再検証） |
| 文字の誤り、視認性 | P4〜P5（該当番号だけ再作成） |
| タイトル・説明・コピーライト | P7 |
| 権利確認書類の要求 | ユーザーに書類提出を依頼。エージェントは書類を作らない |
| 肖像権・権利不明 | P0（権利を再確認。満たせなければ私的利用に切替） |

再申請でも「審査をリクエスト」はユーザーが押す。
