# LINE Creators Market仕様メモ（静止画スタンプ）

P6とP8で必ず公式の現行ページを確認し、差異があればローカル資料ではなく公式を優先する。

- 制作ガイドライン: https://creator.line.me/ja/guideline/sticker/
- 審査ガイドライン: https://creator.line.me/ja/review_guideline/

## 画像

| 素材 | 数 | サイズ | 形式 |
|---|---:|---:|---|
| メイン画像 | 1 | 240×240 | PNG |
| スタンプ | 8/16/24/32/40 | 最大370×320 | PNG |
| トークルームタブ | 1 | 96×74 | PNG |

- 画像サイズは偶数、RGB/RGBA、72dpi以上
- 1ファイル1MB以下、ZIPは60MB以下
- 背景透過、外枠からコンテンツまで約10pxの余白
- 個数は登録画面で先に選び、審査リクエスト後は変更できない

## テキスト

| 項目 | 制限 |
|---|---|
| タイトル | 2〜40文字。英語は必須、日本語は言語追加で入力 |
| 説明文 | 10〜160文字。英語は必須 |
| クリエイター名 | 50文字以内 |
| Copyright | 50文字以内。半角英数字（例: `(c)2026 CreatorName`） |

- 英語欄に全角文字・全角記号・全角スペースを入れない
- URL、告知文（「◯月◯日発売」「◯◯で検索」）、絵文字・機種依存文字、他メッセンジャーサービス名を入れない
- 「LINE」の文字は入れない
- タグは1スタンプにつき最大9個

## 審査で落ちやすい点

- 実写切り抜き、8頭身の全身など視認性が悪いもの
- スタンプ内の文字の誤り、タイトル・説明との矛盾
- 許諾のない人物の顔・似顔絵（5.3）、権利の所在が不明なキャラクター（5.2）
- AI生成のみで制作したものは審査対象外になる場合がある。文字合成・切り抜き・レビューなどの制作工程をSESSIONへ残し、AI使用は申告欄で正直に選ぶ

## 販売設定

- 価格は登録画面の選択肢から選ぶ（例: 120円〜）。現行の選択肢は画面で確認する
- 販売地域: 全エリア／選択エリア
- プライベート設定: LINE STOREに公開／非公開（非公開でも購入リンク共有は可能）
