# 申請メタ案（P7）

人物写真由来・既存キャラ由来のどちらでも、タイトルと説明へ実名を書かず承認されたキャラ名を使う。`publish: yes` かつ `consent: yes` かつ `adult: yes` かつ `rights: own|licensed` でなければ、公開申請の案内を行わず私的なお試しパックまでにする。

用意する案（`meta/submission.json` に保存。形式は [submission.example.json](submission.example.json)）:

- 日本語タイトル: 全角20文字程度を目安（上限40文字）
- 英語タイトル: 短い英題。全角文字を含めない
- 日本語説明: 日常での用途を10〜160文字で
- 英語説明: 同上。全角文字を含めない
- クリエイター名: 実名を避けた表示名（50文字以内）
- コピーライト: 半角英数字のみ、50文字以内
- 価格: 登録画面の選択肢から
- 販売地域: 全エリア／選択エリア
- プライベート設定: 公開／非公開
- AI使用: 使用した事実を申告欄で選択する
- タグ案: 各スタンプに最大9個。P3の表情・用途から機械的に候補を作る

`scripts/check_publish_ready.py` を通し、エラー0でユーザーにメタ案を提示する。承認後に [publish.md](publish.md) の P8 へ進む。

ZIPには `main.png`、`tab.png`、規定数のスタンプPNGだけを入れる。提供写真、三面図、レビュー一覧、SESSION、メタ文書は入れない。
