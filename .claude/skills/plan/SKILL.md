# /plan

1. `tasks/todo.md` が進行中なら内容を確認し、新規計画で上書きしてよいかユーザーに聞く。完了済みなら `tasks/history/YYYY-MM-DD-<topic>.md` へ移してから始める
2. `tasks/todo.md.template` をコピーし、次を埋める
   - 目的（1〜2文）
   - 影響範囲（変更するファイル・変更しないファイル・実行時に生成されるもの）
   - ステップ（チェックボックス。各ステップに検証方法を添える。最後に必ず「動作確認」と「レビュー記入」を置く）
3. スタンプ制作の依頼なら、ステップをゲート P0〜P9 に対応させ、各ゲートの承認をステップに含める
4. 計画を提示し、「この計画は目的・スコープに合致しているか」を自問したうえで承認を求める。承認前に実装しない
