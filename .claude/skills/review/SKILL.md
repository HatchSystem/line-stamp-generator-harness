# /review

対象を特定し、次の観点で確認して「違反 / 懸念 / 改善案」の3区分で報告する。修正はしない。

## コード・設定の変更

- `AGENTS.md` の禁止事項に触れていないか（rm -rf、force push、不可逆ボタン、認証情報）
- 変更が最小スコープか。影響範囲が todo.md の記載と一致するか
- 動作確認の証跡（テスト出力・ログ・画像）があるか

## 確認一覧（P5）

- 全番号が同一キャラに見えるか（顔・髪・服・配色）
- 誤字、文字の縁取りの影・ずれ、白い島、切り抜き漏れ
- 濃色背景でも確認したか。版番号が上がっているか

## メタ案（P7）

- `.claude/rules/line-compliance.md` のテキスト制限（文字数・全角・禁止語・URL・告知文）
- 実名不使用、AI 使用申告、`consent` `adult` `rights` の整合
- `check_publish_ready.py` の出力が errors=0 か
